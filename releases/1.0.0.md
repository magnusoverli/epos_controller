# Headset Controller for Linux 1.0.0

Released **2026-10-15** · Tag **v1.0.0** · MIT licensed

The first release of an independent Linux controller for the **EPOS IMPACT 860T
ANC** (USB `1395:018e`), built with C++23 and Qt Quick. No proprietary EPOS SDK is
required or included.

## Highlights

- **Device settings:** 19 readable headset settings covering ANC/TalkThrough,
  sidetone, audio limiting, boom/wear behavior, prompts and languages, ringtone,
  Busylight and buttons, plus a confirmed Factory Reset action.
- **Responsive controls:** dropdowns save on selection; sidetone saves on
  mouse/touch release. Changes are serialized and verified against device
  readback in the background, with errors shown at the affected control.
- **Collapsible settings:** sections start collapsed, have clear disclosure
  arrows, and remember their expanded state while navigating within the app.
- **Persistent Linux access:** one-time authorization installs model-specific
  udev permissions; same-unit reset/replug recovery reloads settings automatically.
- **Mute notifications:** desktop alerts and an audible cue routed directly to
  the selected headset, with locally saved mode and interval preferences.
- **Firmware discovery and installation:** actual installed-version readback,
  automatic EPOS production-catalog checks, and user-initiated upgrades. Downloads
  are checked against catalog hashes and package/model/version metadata; the
  update flow tracks reboot, verifies the final version and records interruptions.
- **Diagnostics:** GUI and display-free USB/HID diagnostics, JSON export,
  settings/firmware reads and offline firmware-package inspection.

## Download and build

This is a **source release**. Download the source ZIP or tar.gz from this release,
or check out the versioned tag:

```sh
git clone --branch v1.0.0 --depth 1 https://github.com/magnusoverli/epos_controller.git
cd epos_controller
cmake --preset release
cmake --build --preset release --parallel
./build/release/headset-controller
```

Dependencies: Linux, a C++23 compiler/standard library, CMake 3.24+, Ninja,
Qt 6.12+ (Core, Gui, Qml, Quick, QuickControls2, Network and DBus), libudev,
libarchive and pkg-config. Default test-enabled builds also require Qt Test,
Python 3 and `dbus-run-session`. Supply `-DCMAKE_PREFIX_PATH=/path/to/Qt` when
configuring with a non-system Qt SDK. Run the app as your normal desktop user.

Automatic access setup needs PolicyKit and a desktop authentication agent.
Headset audio alerts use `paplay`/`pactl` from `pulseaudio-utils`, including on
PipeWire-Pulse systems. HTTPS requires a working Qt TLS backend and CA certificates.
See the [versioned README](https://github.com/magnusoverli/epos_controller/blob/v1.0.0/README.md)
for full build, installation and runtime requirements.

## Validation and known limitations

- Release and ASan/UBSan test suites cover all 14 test groups, including
  normal/high-DPI UI interactions. QML lint, formatting and relocated-install
  checks are included in release validation.
- All 19 settings getters have successful Linux device readback. Sidetone 32/33%,
  ANC Off/On, Adaptive Off/On and Middle/High ANC level have live change-and-restore
  validation. Newer setters, expanded sidetone/TalkThrough/Low ANC and Factory
  Reset still need broader hardware validation.
- **Native firmware flashing has not yet been hardware-tested.** The engine
  passes byte-for-byte replay of a successful vendor Web upgrade from 1.5.64 to
  1.5.619 and synthetic future-release tests. Reinstalls and downgrades are
  disabled; interrupted updates have no automatic resume or rollback.
- Support targets the IMPACT 860T ANC; other headset models are not validated.
  Application preferences remain unfinished, and full Windows feature parity
  is not claimed.
- No prebuilt installer or bundled Qt runtime is attached to this release.
